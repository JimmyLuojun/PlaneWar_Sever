PlaneWar is a desktop game client written in Python. It needs to connect to this running web server to handle user login and leaderboard scores.

Setup and Execution:

1. Prerequisites:

  • Ensure you have Python and Poetry installed.
  • Get the Game Code: clone or download the project.
  • Ensure the Server is Running: run it in a separate terminal.

2. Running the Game Client:

  1. Open Terminal and navigate to the project directory.
  2. Install dependencies: 
    poetry install
  3. Run the game client: 
    poetry run python -m game.main

3. Login and Play:

  • The PlaneWar game window should open.
  • Log in with the same credentials you use on this website.

4. Check Your Score:

  • Scores are submitted to this server via /api/submit_score.
  • View rankings on the Leaderboard page.
